# PlugNX Settlement OS Intro

공개 소개 사이트: `/plugnx-app/settlement-os/`

## 핵심 체험
- Visa × Life Event × 거주목적 × 우선순위 Journey Composer
- 명시적 사용자 선호 기반 Community Fit
- Job → Home → Move/Storage/Clean → Mobility → Stay/Visa → Finance
- Arrival → Stabilize → Upgrade → Settle → Own Settlement Ladder
- 비자·상황별 Journey
- 중고차를 별도 마켓이 아니라 Mobility Decision으로 연결
- Rent/Jeonse/Buy → AVM → Finance → Appraisal → Electronic Registry
- BM: Free Decision → Execution → Sponsor SaaS → Financial Bridge → Infrastructure

모든 지역 점수·가격·금융 결과는 서비스 개념 설명을 위한 DEMO 데이터입니다. 비자·보증·금융의 실제 가능 여부는 최신 공식 규칙과 권한 있는 파트너 절차로 판단해야 합니다.
